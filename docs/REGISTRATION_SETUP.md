# Подключение регистрации и команды эфира

Развёртывание создаёт D1 `DB` и R2 `MEDIA`; миграции в `drizzle/` применяются платформой.

Для отправки кодов настройте переменные проекта:

| Переменная | Назначение |
|---|---|
| RESEND_API_KEY (secret) | Ключ почтового API Resend |
| MAIL_FROM | Подтверждённый адрес отправителя, например «Телецентр INVITRO <адрес@ваш-домен>» |
| EMPLOYEE_EMAIL_DOMAINS | Разрешённые рабочие домены через запятую, задаются организаторами |
| STUDIO_LOGIN | Логин для `/admin` и `/studio` |
| STUDIO_PASSWORD (secret) | Пароль для входа с логином |
| STUDIO_ACCESS_TOKEN (secret) | Длинный ключ для подписи ссылок vMix и входа по ключу при пустом поле «Логин» |

Не размещайте эти значения в клиентском коде. После изменения переменных разверните новую версию. SMTP/Resend не настроен в текущем проекте: реальные письма пока не отправляются. Тесты используют изолированный транспорт и не отправляют почту.

Состояние до открытия регистрации: страница доступна; 3D-прогулка и игры работают; билеты и заработанные баллы закрепляются за подтверждённым кабинетом. Реестр считает только записи D1. Пока он пуст или ещё не подключён, интерфейс и 3D-студия показывают явно обозначенный пример наполнения — 8 742 шара. При первой регистрации представление переключается на реальный счётчик; фиктивные билеты в базу не добавляются. Обращения поддержки доступны без входа и сохраняются в очереди команды; это не отправка в почтовый ящик.

Текущий порог второго билета: 100 баллов (две студии по 50 один раз) + 600 активных секунд. Идентичные повторные запросы не выпускают лишние билеты. Общий пул — 13 000 номеров. Номера привязаны к почте; если сотруднику разрешены несколько рабочих адресов, перед большим запуском нужен кадровый реестр единого employee ID. Текущая проверка домена подтверждает владение рабочей почтой, но не заменяет такой реестр.

Пульт `/studio` показывает медиапортреты, поздравления и обращения, позволяет просматривать и скачивать материалы. Учётные данные хранятся в памяти вкладки и проверяются сервером для каждого запроса. Фото/голос/видео не имеют публичных URL.

Проверка: `node tests/participant-flow.mjs` — настоящие обработчики с временной SQLite, имитацией R2 и почты: OTP, повторы, сессии, 2 билета, время, баллы, приватность файлов, сообщения и выход.

Визуальная проверка: desktop и мобильная ширина 375 px, два билета в кабинете без горизонтального переполнения, белый header, увеличенный музыкальный экран, переходы в подиум и гримёрку. Cloud-браузер использует режим без WebGL: подтверждён активный RADIO_STUDIO_motion.webp, полноценная GPU-проверка и микрофон/камера на физическом iPhone остаются отдельными проверками. Временные страницы проверки удалены из публикуемой версии.

## Стол заказов и Утренняя почта — 27.09.2026

`/api/messages` принимает гостевые поздравления и открытки. Имя/должность берутся из кабинета, если он открыт, но вход не требуется. Текст либо файл до 25 МБ сохраняются одним запросом; сервер проверяет согласие, источник запроса, формат и лимит 5 сообщений с IP за час. Идентификатор попытки предотвращает дубли при повторе. IP хранится в виде хеша и не выдаётся в интерфейс редактора. Медиа остаются приватными.

Три шаблона открыток — оригинальные ImageGen-иллюстрации, сведения о происхождении в `docs/postcards-provenance.json`. Формат письма: выбранная иллюстрация, имя получателя, текст поздравления и подпись. Перед отправкой пользователь проверяет адрес и дизайн. HTML экранируется сервером. Копия для редактора сохраняется в D1 сразу. Статус `sent` означает принятие письма почтовым сервисом, а не подтверждённое прочтение или доставку в Inbox.

Почтовая отправка использует те же RESEND_API_KEY и MAIL_FROM. Без них открытка остаётся `queued`; форма сообщает об ожидании. После подключения почты команда открывает `/studio` и отправляет сохранённые открытки кнопкой; запросы к почте имеют ключ идемпотентности. Пульт доступен после проверки учётных данных команды.

Миграция `0001_productive_blade.sql` добавляет только `broadcast_posts`; применённая 0000 не менялась. Тесты проверяют гостевой голос/текст, согласие, повторы, приватность, почтовые ошибки, очередь, действия редактора и экранирование HTML. Тестовый транспорт не отправляет реальные письма.

В радиостудии три записи: существующая «Снег кружится» и две короткие оригинальные инструментальные аранжировки традиционных public-domain мелодий Jingle Bells и Deck the Halls. Исходник аранжировок — `scripts/audio/radio-miniatures.py`; исходные записи третьих лиц для них не используются. Выбор песни передаётся вместе с приветом редактору, но не меняет публичную эфирную сетку для всех участников.
